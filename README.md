# LIJ//CERNA — GitHub Pages Portfolio

A GitHub-ready portfolio website for Lan Ian Jay B. Cerna.

## Files

- `index.html` — page structure and content
- `style.css` — design, responsive layout, and print styling
- `script.js` — mobile menu, PDF printing, and contact form
- `images/portrait.png` — profile portrait

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `lij-cerna-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the live website address.

## Editing

Most information can be edited directly in `index.html`.

To replace the portrait, upload a new image to `images/` and change:

`images/portrait.png`

inside `index.html`.

## Contact form

The contact form uses `mailto:`. It does not require PHP or a database. It opens the visitor's default email application and prepares an email addressed to `lanianjayc@gmail.com`.

## Portfolio assets

The current version uses the supplied portrait. Additional portfolio images can be added later to the `images/` folder and inserted into a dedicated portfolio/gallery section.
